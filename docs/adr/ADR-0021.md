# ADR-0021: Decision Traces Are Mandatory

- Status: Accepted
- Date: 2026-03-16
- Deciders: Architecture Office (TEAM-090)
- Related: ARCH-06, ARCH-07, ADR-0008, ADR-0013, ADR-0020, ADR-0037

## Context

Decision Intelligence is the sole orchestrator (`ADR-0008`) — the only layer with agency. That
concentration only delivers auditability if DI's choices are *recorded*. Every task involves a
chain of control decisions: how the intent was interpreted, what plan was formed, which model
was routed to and why, when the Worker proceeded versus re-retrieved versus escalated, and
which policy gates fired. If those choices are not captured, "opaque decisions" become the
failure mode — a Worker acts and no one, including the Learning Engine, can explain why. And
without the reasoning trail, deterministic replay (`ADR-0037`) is impossible.

We must decide whether DI's reasoning is recorded or transient.

## Decision

We will require Decision Intelligence to **emit a mandatory decision trace** for every task:
each choice, its rationale, the fused confidence (`ADR-0013`) it was made at, the model routed
to, the policy checks applied, and the control action taken (proceed / re-retrieve / replan /
retry / escalate / abort). The trace references artifacts by canonical ID (`ADR-0022`,
`ADR-0023`) and, together with the immutable context provenance (`ADR-0020`) and the assembled
`CTX-###`, forms the complete, replayable record of a task. No unexplained action is permitted:
an action absent from the trace is a defect.

## Consequences

- **Positive.** Worker behavior is fully explainable from one artifact per task; audit,
  reflection, and human review all read the same trace. This is what turns "concentrated agency"
  (`ADR-0008`) into "auditable agency."
- **Positive.** Decision traces are the input to deterministic replay (`ADR-0037`) and to the
  Learning Engine's analysis of which control decisions were vindicated by outcomes.
- **Negative.** Every control decision must be instrumented and persisted, adding overhead and
  storage; verbose traces must be structured (not free text) so they stay queryable and don't
  become write-only.
- **Neutral.** The trace records *decisions*, while provenance records *inputs* and evaluation
  records *judgments*; together they cover the full task, each owned by its respective layer.
