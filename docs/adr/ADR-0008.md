# ADR-0008: Decision Intelligence Is the Sole Orchestrator

- Status: Accepted
- Date: 2026-01-29
- Deciders: Architecture Office (TEAM-090)
- Related: CANON-001 §9 (Stage 3), ARCH-06, ARCH-07, ADR-0014, ADR-0021

## Context

An ECL task traverses many layers — context assembly, planning, model calls, execution,
evaluation, learning. *Something* has to sequence them, decide when the task is done, choose
when to retry versus escalate, and enforce policy before acting. If that agency is distributed
— if the Context Layer can decide to act, or the Execution Runtime can decide to replan, or
each layer makes its own control choices — then Worker behavior becomes an emergent property
of many interacting components, which is nearly impossible to audit, reproduce, or benchmark.

We must decide where *agency* lives in the architecture.

## Decision

We will concentrate all agency in **Decision Intelligence (DI, `ARCH-06`)** as the sole
orchestrator. DI is the only layer that *decides*: it interprets intent, forms plans
(`PLAN-###`), requests context, routes model calls through the Gateway, issues execution
directives, consumes evaluation verdicts, and chooses whether to proceed, re-retrieve,
replan, retry, escalate, or abort. Every other layer *serves* — the Context Layer assembles,
the Knowledge Layer knows, the Evaluation Layer judges, the Learning Engine improves — but
none of them takes autonomous control action.

DI emits a mandatory decision trace (`ADR-0021`) for every choice, and its autonomy is gated
on fused confidence (`ADR-0014`) with policy enforced before execution (`ADR-0041` in the full
catalog).

## Consequences

- **Positive.** Worker behavior has a single, inspectable control point. Auditing "why did the
  Worker do that?" means reading one decision trace, not reconstructing emergent cross-layer
  interactions — the precondition for a trustworthy benchmark.
- **Positive.** Safety properties (confidence gating, policy stops, iteration budgets) are
  enforced in one place and cannot be bypassed by a layer acting on its own.
- **Negative.** DI is a potential bottleneck and a single point of complexity; it must not
  absorb responsibilities that belong to serving layers (assembling, knowing, judging), or it
  becomes a god-object. The boundary is enforced by ADRs `0006`, `0007`, `0015`.
- **Neutral.** Future multi-Worker collaboration (`ARCH-07`) is still orchestrated *by* DI,
  which coordinates specialized Workers rather than letting them self-organize.
