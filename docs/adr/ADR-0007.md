# ADR-0007: Knowledge Is the Only Source of Enterprise Truth

- Status: Accepted
- Date: 2026-01-26
- Deciders: Architecture Office (TEAM-090)
- Related: CANON-001 §9, ARCH-02, ADR-0004, ADR-0006, ADR-0036

## Context

The ECL has several stores that hold enterprise information: the Knowledge Layer (governed
truth), the Experience Layer (earned lessons), the Context Layer (ephemeral working sets), and
the model's own parametric "knowledge." If any of these can independently assert enterprise
truth, Workers will get conflicting facts, evaluations cannot decide which source to judge
against, and the same question answered from two stores may diverge. A benchmark cannot
tolerate ambiguity about *what is true about MCG*.

We must designate exactly one authoritative source of enterprise truth and define how the
other stores relate to it.

## Decision

We will make the **Knowledge Layer the single source of enterprise truth**, rooted in
`CANON-001`. Only `KN-###` objects (and the canon they descend from) are *authoritative* about
what is true at MCG. The other stores are explicitly *not* truth:

- **Experience** (`ARCH-03`) holds *what worked or failed* — lessons awaiting or graduated to
  promotion — not truth. A lesson becomes truth only by governed promotion into Knowledge
  (`ADR-0036`).
- **Context** (`ARCH-01`) is ephemeral and never authoritative (`ADR-0006`).
- **The model's parametric knowledge** is generic and untrusted for enterprise facts; it must
  never be treated as a source of MCG truth.

Contradictions between knowledge items are surfaced and resolved through governance, with
canon breaking ties. Live enterprise state (code, catalog, telemetry) is authoritative for its
*own volatile facts* and is preferred over cached knowledge for those, but it is read through
the Context Layer and does not replace governed knowledge for durable rules.

## Consequences

- **Positive.** There is always one answer to "what is MCG's rule here," which makes
  evaluation against standards (`ADR-0015`, `ADR-0016`) well-defined and makes Worker behavior
  arguable against a fixed bar.
- **Positive.** A clean promotion boundary (experience → knowledge) prevents unvetted lessons
  or model hallucinations from silently becoming enterprise truth ("poisoning").
- **Negative.** Knowledge must be actively curated and kept fresh (`ADR-0046`), or Workers face
  knowledge gaps and fall back to weaker sources; the governance path is a real cost.
- **Neutral.** The distinction "truth vs. lesson vs. live fact" must be modeled explicitly in
  schemas and retrieval so the layers never blur, especially during hybrid retrieval
  (`ADR-0019`).
